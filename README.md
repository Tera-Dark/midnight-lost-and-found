# 凌晨失物处 · Midnight Lost & Found

> 请将他归还给她。认领期限：永久。

原创现代都市奇幻 / 微悬疑 / 情感向 / 角色驱动世界观与 OC 企划。

**故事核心：** 苏杳替别人寻找遗失之物，江寻却是一个连自己曾经存在过都无法证明的人。在只于凌晨接待来客的失物事务所，他们调查异常遗失物，也逐渐接近各自缺失的过去。

## 项目原则

- **日常里的微妙异常：** 便利店、末班地铁、旧公寓、门禁卡、照片、档案纸；不堆砌魔法和大型组织。
- **先有人，再有异常：** 每件失物引出一个选择，而非纯粹展示超能力。
- **归还不等于修复：** 找回物品不意味着时光倒流或关系复原。
- **人物关系有独立生命：** 苏杳和江寻的情感发展不能只依靠失忆谜底。
- **不擅自冻结悬念：** 将确认设定、工作假说、备选方案分开保存。
