# 江寻 · Jiang Xun

> CHARACTER FILE 002 · 当前造型依据作者 2026-10-27 正式提示词与新立绘。人物核心经历沿用 v1.0。

**身份**：零号失主 / 凌晨失物事务所非正式搭档  
**年龄**：外表约 27 岁；真实年龄未知  
**气质**：随和、敏锐、克制、擅长用玩笑隐藏疲惫  
**主题句**：他想找到一个能够证明自己曾经存在过的人。

## 外貌与服装 · 现行版

- **身形**：成年男性，修长高挑，肩较宽、腰细、长腿，五官清俊，浅肤色。
- **脸与头发**：疲倦的灰色下垂眼，淡淡微笑；**纯黑色中长狼尾发（wolf cut / mullet）**，蓬松凌乱、分层明显，刘海参差，遮过一侧眼睛，侧发较长，后颈发尾外翘。
- **耳饰**：黑色耳钉。
- **上装**：灰褐（taupe）麂皮材质**短款**夹克，立领、结构肩线、宽松长袖、非对称银色纽扣；**领口其中一枚为不匹配的古银替换扣**。内搭黑色翻领衬衫，领口自然微敞。
- **下装**：炭灰高腰宽松褶饰阔腿西裤，黑色腰带与银色扣头。
- **鞋与戒指**：抛光黑色皮鞋；**右手食指**戴有磨损痕迹的银戒指。
- **姿态**：重心偏向一侧，微微歪头，一手插袋、一手自然垂下，注视观众。

## 角色性格

他离开他人的视线一段时间后，名字和面貌会渐渐被遗忘，电子身份记录也不稳定。他不愿强迫任何人记住自己，便把失落说成玩笑。苏杳却始终能够记住他。

## 视觉锚点

**发型**：纯黑层次狼尾发、遮眼不齐刘海。  
**服设**：灰褐麂皮短夹克 + 黑色衬衫 + 炭灰阔腿长裤。  
**配饰**：不匹配的古银领扣、黑耳钉、右食指旧银戒。  
**配色**：灰褐 / 黑 / 炭灰 / 古银。
