# 世界观核心（v1.1 工作稿）

> 状态：**CANON / 已确认底稿整理**，依据《凌晨失物处》v1.0。此文仅凝练原稿，没有提前揭晓秘密。

## 创作定位
不具名现代大都市；绝大多数市民不知晓异常。奇异现象潜藏于习以为常的载体中。整体基调：克制、现代、精致、轻微超现实，不走赛博朋克或夸张魔法体系。

## 一句话剧情
苏杳替别人找回遗失之物，江寻却是一个连自己曾经存在过都无法证明的人。

## 核心主题
- **遗失与找回：** 遗忘不等于不存在。
- **证据与身份：** 当记录消失，谁有资格证明一个人的存在？
- **归还与选择：** 找回不代表修复；当事人拥有面对或不面对往事的权利。
- **亲密与记忆：** 爱不等于永久占有他人，记住也不能代替尊重。
- **档案与人生：** 记录可以提供证据，却不能为一段人生作最终裁决。

## 已确立的世界事实
1. 城市具备现代地铁、数字档案、老旧居民区、社交网络等。
2. 异常遗失物可能携带强烈的记忆、情感或身份痕迹；外观往往普通。
3. 事务所在凌晨接待来客，接收、登记、调查、归还、归档异常遗失物。
4. 事务所不改变过去，不保证每件失物归还，不代替失主作决定。
5. 没有明确失主的遗失物更危险，可能影响记忆与认知。
6. 在极少数情况下，身份记录与他人记忆会逐渐失效；不同媒介消退速度不一致。
7. 江寻会逐渐从其他人的记忆中淡去；苏杳目前能稳定记住他。
8. 苏杳缺乏十九岁以前可靠的个人记录；江寻的历史也存在无法证明之处。
9. 纸质零号档案编号 000；登记日期是苏杳十九岁生日前一天；备注为“请将他归还给她。认领期限：永久。”

## 核心人物

### 苏杳
档案员 / 失物复原师，约二十四岁。冷静、敏锐、克制；倾向用具体行动表达关心。长于帮别人寻找来处，却不愿面对自己的空白过去。

### 江寻
零号失主 / 非正式夜班搭档。外表约二十五至二十八岁；随和、擅长玩笑，疲惫但不愿把困境强加于他人。他渴望有人记住自己，却早已习惯关系被世界擦去。

## 不应提前下定论
- 异常的起源、科学或超自然实质。
- 事务所由谁设立、是否存在其他同类机构。
- 苏杳十九岁以前发生什么，她是否主动遗忘。
- 江寻是何种存在，他的名字是否真实。
- 零号档案所指的“他”究竟是谁。
- 两人在过去是否相识及最终关系/结局。

## 情感调性边界
少用宏大救世叙事和神秘组织大战；多用生活细节、抉择后的余波、能反复呼应的物件。不能将“苏杳是唯一锚点”简化成控制或剥夺江寻自由的借口。
