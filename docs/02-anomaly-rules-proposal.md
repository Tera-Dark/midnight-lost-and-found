# 异常机制：三层模型（PROPOSAL / 待审议）

> **不是正史。** 以下是为填补初稿中的因果空白提出的统一模型；可整套采用、局部采用或否决。

## 设计目标
让所有异常案例共享一套底层逻辑，同时保持神秘气氛；足以约束情节，而不把都市奇幻变成数值化超能力系统。

## 1. 痕迹、归属、见证
- **痕迹（Trace）：** 人与经历在物件、记忆、习惯、档案中留下的可辨认残余；不是灵魂货币。
- **归属（Claim）：** 一件物品/一段关系/一个名字指向特定经历的可追索联系；法律持有人未必是叙事中的真正失主。
- **见证（Witness）：** 独立于当事人的证据或记忆，能帮助确认痕迹的来处；见证者并不自动拥有处置权。

**工作假说：** 异常发生在“痕迹仍在，但可被世界稳定识别的归属断裂”时。物品于是成为矛盾的载体。

## 2. 四类现象（临时分类）
| 类别 | 表现 | 适用故事 |
|---|---|---|
| 遗留 | 该消失的信息保存在异常载体中 | 未发送的语音 |
| 错位 | 物品指向不再存在的空间或时刻 | 被拆除公寓的门禁卡 |
| 脱名 | 记录仍在却失去明确的人的对应关系 | 模糊人脸、无人认领档案 |
| 回返 | 物件被反复归还、重新出现，未结之事持续显影 | 无人认领的外套 |

分类只用于案件归档，不代表四种不同魔法力量；同一案件可叠加标签。

## 3. 有限信息原则
异常**不能**凭空生成准确的全部历史，也不能随意改写过去。失物携带的是片段线索，可能残缺、误导、受当事人的主观认知影响。调查仍需实地采访、核对时间、寻找独立见证。

## 4. 有代价但不机械化
建议将危险写为可观察的“认知侵蚀”而非通用生命值：
- 轻度：错记时间、忽略某个熟悉名字。
- 中度：照片与证词互相矛盾，人与物的归属开始错位。
- 重度：与特定人的关联被大范围弱化，成为近似“无主”状态。

**边界：** 这不是所有失物都会升级的固定阶梯；危害由案件触发条件、接触时长与归属状态决定，尚不量化。

## 5. 不可滥用的五项硬限制（建议）
1. **不可逆转既成事实：** 找回痕迹不能起死回生或重写重大历史。
2. **不可一键判定真相：** 任何人或设备都没有万能读心/读取过去能力。
3. **不可保证善果：** 正确归还也可能造成现实中的痛苦。
4. **不可强迫认领：** 拒绝接收也是选择；要区分封存与销毁。
5. **不可无条件免疫：** 苏杳对江寻的稳定记忆是核心谜团，不能顺势推导为她对所有异常免疫。

## 6. 需要专门做实验的边界案例
- 复制同一张照片十份，十份都会失真吗？
- 旁人把江寻的名字写在手心，多久会无法理解文字？
- 苏杳直播介绍江寻，会不会突破遗忘现象？
- 失主已去世，遗物能否归还给继承人？
- 两人都声称某件物品属于自己，事务所怎么判定？
- 一个不愿找回记忆的人，可否永久撤回申请？

**决议建议：** 优先确认“异常存在的原因模型”和“记忆衰退的可观测规则”，再创作依赖规则的关键反转。
