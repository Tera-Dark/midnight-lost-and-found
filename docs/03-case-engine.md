# 事务所运行逻辑与单元故事引擎（PROPOSAL）

> 扩展提案，非全部正史。基准是初稿中的五段流程：接收、登记、调查、归还、结案。

## 事务所的存在必要性
如果异常只是怪事，警察、医院、普通失物招领处似乎也能处理。建议明确事务所的独特职能不是“打怪”，而是**对无法稳定归属的事件保全痕迹，核查当事人意愿，提供非强制归还渠道**。

## 案件档案的最小字段
- 编号；接收时刻；载体描述；发现位置
- 申报人；疑似失主；独立见证者
- 异常表现；重复验证结果；接触注意事项
- 关联情绪或争议；失主的真实诉求
- 归还决定（交付 / 拒收 / 暂存 / 转交 / 无法查证）
- 结案后果；与主线的弱关联线索

“结案”不等同于“物归原主”。拒收和无法查证也能作为诚实的结局。

## 三条职业伦理（建议）
1. 证据优先于直觉；不要以“感应”代替调查。
2. 保护失主的隐私与选择权；异常信息不成为胁迫工具。
3. 发现利益冲突时，事务所必须记录分歧；苏杳涉及自身过往的案件，不能只靠她的独断结案。

## 单元故事六拍
1. **普通入口：** 以小物件与现实请求引入。
2. **一处不对：** 异常只在一个细节暴露。
3. **错误解释：** 角色依据偏见做出合理但不完整的推断。
4. **人际真相：** 找出并非物件本身的核心矛盾。
5. **选择与代价：** 给当事人可拒绝、可承担后果的选择。
6. **余波与回声：** 留下一个和苏杳/江寻形成对照的动作或证据。

## 防重复原则
至少在三条轴上变化：
- **当事人关系：** 亲情、友情、旧爱、师生、邻里、陌生人、自我认同。
- **归还结果：** 找回、放弃、拒收、代为保管、分割归属、无主暂存。
- **角色冲突：** 苏杳坚持登记事实，江寻更在意个人体验；也应存在角色立场反转。

## 主线渗透节奏（结构建议）
- 前期：以2—3个完整单元树立规则，零号档案只作为背景伏笔。
- 中期：出现与苏杳空白历史、江寻脱名现象有交集的案子；每次揭示一项可验证事实。
- 后期：主线冲突迫使二人选择，不能把“真相揭露”当成全部高潮。

## 剧情校验清单
- 异常是否改变过去？若是，违反已确认的事务所限制。
- 主角是否凭不曾建立的能力轻松解谜？
- 失主是否真正有选择权？
- 同样规则在江寻身上是否也成立，例外有无伏笔？
- 该案结束后人物关系或世界认知有没有留下持久变化？
